Задание 1. Итератор для списка списков (task_1.py)
Как работает: два «курсора» — внешний (по вложенным спискам) и внутренний (по элементам внутри списка). Когда внутренний список заканчивается, курсоры сдвигаются к следующему. Когда все перебрано — StopIteration

Задание 2. Генератор (task_2.py)
Как это работает: наличие yield внутри функции делает ее генератором — при вызове она не выполняет код, а возвращает объект-генератор, который выдает по одному элементу на каждый next().

Задание 3*. Итератор с любой глубиной вложенности (task_3.py)
Как это работает: вместо курсоров используем стек итераторов. Наткнулись на список — положили его итератор на вершину стека и работаем с ним; список закончился — снимаем со стека и возвращаемся к родителю. Пустые списки [] обрабатываются автоматически (сразу StopIteration → pop).

Задание 4*. Генератор с любой глубиной вложенности (task_4.py)
Как работает: рекурсия + yield from. Если элемент — список, генератор вызывает сам себя для него и делегирует выдачу всех его элементов. Важна именно проверка isinstance(item, list), а не Iterable, так как строка 'a' — это итерируемый объект, и при проверке через Iterable она бы распалась на символы (или зациклилась бы).
